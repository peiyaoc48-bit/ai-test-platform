## 1. 要回答的问题

1. 大模型把一份真实的需求文档拆成需求点、再生成用例，**人工审核后有多少能直接用**？（采纳率，带 95% Wilson 置信区间）
2. 被废弃、被修改的主要原因是什么？这些原因能不能指导改 Prompt？
3. 根据废弃原因改出的 `gen-v2`，采纳率比 `gen-v1` **有没有显著提高**？（Fisher 精确检验）
4. 同一份输入重复生成，结果的波动有多大？（用来判断 v1 与 v2 的差异是不是只是随机波动）

## 2. 数据来源

- **需求文档**：作者毕业设计论文（在线考试智能监考系统）第 3.2 节“功能需求分析”，约 2400 字，包含用户与考试管理、行为检测与异常判定、实时预警与监考报告、非功能需求四部分。
- 论文尚未公开，**需求原文不放进本仓库，也不导入公开演示站**；本文只记录需求点数量、采纳率等统计数字，必要时引用个别需求点的标题。
- 目标 URL：本机运行的被测系统首页（只用于告诉模型页面入口，生成阶段不访问它）。
- 不使用任何实习单位的系统或数据。

## 3. 实验设计（预先登记）

| 批次 | Prompt | 范围 | 目的 |
|---|---|---|---|
| B1 | `gen-v1` | 全部需求点 | 基线采纳率 |
| B2 | `gen-v1` | 全部需求点（同样输入再生成一次） | 估计重复生成的波动 |
| B3 | `gen-v2` | 全部需求点 | 看改 Prompt 是否有效 |
| B4 | `gen-v2` | 全部需求点（再生成一次） | 同上，再估一次波动 |

- **同一个模型、同一份已确认的需求点**：需求点解析只做一次，由人工检查并修正后锁定，四个批次共用，避免需求点不同影响比较。
- **`gen-v2` 在 B1、B2 审核完之后才写**，内容只依据 B1、B2 里记录的废弃原因，不看 B3、B4。
- 每批样本太少时（已审核少于 20 条），平台会提示“仅供参考”，我照实写“差异不显著”，不下结论。
- **审核由作者本人完成**，不由模型或我代做；审核时逐条看草稿，按下面第 4 节的标准判定。
- 采纳率 = （直接采纳 + 修改后采纳）/ 已审核；“直接采纳率”单列。

## 4. 审核标准（审核前定好）

| 判定 | 标准 |
|---|---|
| 直接采纳 | 步骤和断言正确，去掉括号里的说明后可以原样入库执行 |
| 修改后采纳 | 方向对，但有错别字、断言太含糊、少一步或多一步，改动后可用；改动量由平台自动统计 |
| 废弃 | 不能用，必须选一个原因（下表），只选最主要的一个 |

| 废弃原因 | 含义 |
|---|---|
| 重复 | 和同批或已有用例重复 |
| 需求外（幻觉） | 需求文档里没有这个功能 |
| 无法执行 | 页面上没有对应控件，或步骤写成了无法自动执行的样子 |
| 断言含糊 | 没有可以判断通过与否的具体预期，改动量接近重写 |
| 价值低 | 能执行，但检查的东西没有意义 |
| 其他 | 以上都不是（需要在备注里写明） |

另外，**需求点本身有问题**（摘录在原文里找不到、拆得太碎、拆漏）要单独记在“需求点质量”里，不算进用例采纳率。

## 6. 局限（提前写下）

- 审核人只有作者一人，且知道哪批是 v1、哪批是 v2，**没有盲审**，可能偏向认为 v2 更好。
- 样本是一份需求文档生成的几十条用例，结论只对这一份文档和这个模型有参考价值，不能推广。
- 采纳率衡量的是“人觉得能用”，不等于“用例实际能跑通”。后者要在被测系统上执行入库用例才知道，而被测系统依赖摄像头，自动执行有限制。
- 模型有随机性，同一输入两次生成的结果不同，B2/B4 就是用来估计这个波动的。
